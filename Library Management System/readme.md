# Library Management System

## Overview

The Library Management System is a SQL-based data analysis project designed to manage and analyze library operations. The database stores information about books, members, and borrowing activities, enabling efficient tracking of inventory and user engagement.

This project focuses on transforming raw transactional data into meaningful insights using SQL. It demonstrates database design, data analysis, and reporting techniques commonly used in real-world business environments.

## Database Structure

The project consists of three interconnected tables:

* **Books** – Stores information about books available in the library.
* **Members** – Contains member registration details.
* **Borrow_Records** – Tracks book borrowing and return transactions.

## Objectives

* Analyze borrowing patterns and library usage.
* Monitor book inventory and availability.
* Track member activity and engagement.
* Generate business insights through SQL queries.
* Build a strong foundation in relational database analysis.
