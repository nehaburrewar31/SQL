# Bank Management System SQL Project

 Overview

This project demonstrates a Bank Management System database using SQL. It includes customer, account, and transaction data to practice SQL queries commonly used in Data Analysis and Database Management.

## Database Tables

* Customers
* Accounts
* Transactions

 ## SQL Concepts Covered

* SELECT
* WHERE
* Aggregate Functions (SUM, AVG, MIN, MAX, COUNT)
* GROUP BY
* INNER JOIN
* ORDER BY
* LIMIT

 Project Objectives

* Manage customer and account information.
* Track banking transactions.
* Analyze balances and transaction activities.
* Practice real-world SQL queries.
