# Hospital Management System SQL Project

## Overview

This project is a Hospital Management System database built using SQL. It manages patients, doctors, and appointments while demonstrating essential SQL concepts used in data analysis and database management.

## Database Structure

The project contains three tables:

* **Patients** – Stores patient information.
* **Doctors** – Stores doctor details and specializations.
* **Appointments** – Stores appointment records and consultation fees.

## SQL Concepts Used

* Database Creation
* Table Creation
* Data Insertion
* SELECT Queries
* WHERE Clause
* Aggregate Functions
* GROUP BY
* ORDER BY
* INNER JOIN
* Data Analysis Queries

## Key Analysis Performed

* Total consultation fees collected
* Average, minimum, and maximum consultation fees
* Total appointments count
* Appointments by doctor
* Revenue generated by each doctor
* Patients by city
* Monthly appointment analysis
* Doctor with highest revenue
* Patient with the most visits

## Tools Used

* MySQL
* SQL

## Learning Outcomes

This project helped strengthen SQL skills including data retrieval, data aggregation, joins, grouping, sorting, and analytical reporting.
