# Online Food Delivery Analysis System

## Overview

A SQL-based project designed to analyze customer orders, restaurant performance, food sales, and revenue trends in an online food delivery platform.

## Database Tables

* Customers
* Restaurants
* Food_Items
* Orders
* Order_Items

## Key SQL Concepts

* SELECT, WHERE
* GROUP BY, ORDER BY
* Aggregate Functions
* INNER JOIN
* Subqueries

## Analysis Performed

* Revenue Analysis
* Customer Spending Analysis
* Restaurant Performance Analysis
* Food Sales Analysis
* Order Status Tracking

## Tools Used

* MySQL
* MySQL Workbench

## Outcome

Developed analytical SQL queries to generate business insights and support data-driven decision-making for a food delivery business.
