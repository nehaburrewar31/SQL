# Retail Store Analytics System

## Project Overview

The Retail Store Analytics System is a SQL-based data analysis project designed to analyze sales performance, customer purchasing behavior, product sales, and store revenue. This project helps businesses gain insights into their operations and make data-driven decisions.

## Tools Used

* MySQL
* SQL Queries
* Joins
* Aggregate Functions
* Subqueries
* Common Table Expressions (CTEs)

## Database Tables

* Stores
* Customers
* Products
* Sales
* Sales_Items

## Key Analysis Performed

* Total Revenue Analysis
* Store-wise Revenue Analysis
* City-wise Revenue Analysis
* Product Category Performance
* Customer Spending Analysis
* Top Customers Identification
* Best Selling Products
* Average Transaction Value
* Repeat Customer Analysis
* Monthly Revenue Analysis

## Business Questions Solved

* Total Revenue Generated
* Revenue by Store
* Revenue by City
* Revenue by Product Category
* Top Customers by Spending
* Top Selling Products
* Customers Spending Above Average
* Stores Performing Above Average
* Monthly Revenue Trends
* Repeat Customer Identification

## Key Performance Indicators (KPIs)

* Total Revenue
* Total Orders
* Total Customers

* Top Customer
* Top Product
* Revenue by Category
* Revenue by Store

## Skills Demonstrated

* Data Analysis
* Data Aggregation
* SQL Joins
* Subqueries

* KPI Analysis

## Project Outcome

This project provides valuable insights into retail business performance by analyzing sales transactions, customer behavior, and product performance. The generated reports help stakeholders monitor business growth and improve decision-making.
