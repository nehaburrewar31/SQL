# Employee Sales Performance Analytics (SQL)

## Project Overview

This project analyzes employee sales data using SQL. It covers basic SQL queries and introductory Window Functions to solve real business problems.

## Tools Used

* MySQL Workbench
* SQL

## Database

**Database:** EmployeeAnalytics

**Table:** Employee_Sales

## Dataset

* Total Records: 200
* Departments:

  * Electronics
  * Grocery
  * Fashion
  * Furniture
  * Mobile

## SQL Topics Covered

### Basic SQL

* SELECT
* SUM()
* AVG()
* MAX()
* MIN()
* COUNT()
* GROUP BY

### Window Functions

* ROW_NUMBER()
* RANK()
* DENSE_RANK()
* SUM() OVER()
* AVG() OVER()
* PARTITION BY

## Business Questions Solved

1. Show all employee records.
2. Show employee names and sales.
3. Find total sales.
4. Find average sales.
5. Find highest sale.
6. Find lowest sale.
7. Count total records.
8. Department-wise total sales.
9. Department-wise average sales.
10. Highest sale in each department.
11. Assign row numbers.
12. Rank employees by sales.
13. Assign dense ranks.
14. Calculate running total.
15. Show company average.
16. Show department average.

## Skills Learned

* SQL Basics
* Aggregate Functions
* Window Functions
* Data Analysis
* Business Reporting

## Project Purpose

This project is created for **Data Analyst interview preparation** and to practice SQL using a real-world sales dataset.
